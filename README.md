A spot-the-difference game set in an old orrery keeper's study: two hand-drawn panels side by side, 9 hidden differences across 3 levels, a countdown lamp, limited hints, and mouse plus keyboard play — all offline, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
